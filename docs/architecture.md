# Исследование эталона

Изучен `zqaqzqaqsasha/nizhny-novgorod-2026`, main `ed1a10088e61e7a81392c501e3272b1369026932`, 12.09.2026. Прочитаны index.html, структура assets и data, scripts/update-weather.mjs, sw.js, venue-cards-data.js, venue-cards.js, venue-cards.css, .github/workflows/update-weather.yml.

В эталоне index.html содержит интерфейс, расписание, встроенные стили и большой hero. Venue data отделены от рендера карточки. Модальная карточка поддерживает фотографии, но справочная часть независима от галереи. Поездка опирается на системный шрифт Inter/ui-sans-serif, фон #f6f7f9, текст #202124, границы #d9e0ea, радиус 8 px, синие и зелёные акценты и жирные заголовки. Временная шкала двухколоночная на desktop и одноколоночная на mobile; chips и подсказки компактны.

Дождевой сценарий — переопределения отдельных событий с сохранением общей структуры. В новом проекте тот же принцип, с отдельным выбором для двух дней. Формат данных вынесен в JSON. Галерея не требуется: сомнительные фотографии и старые ассеты не переносились.

В исходнике чек-листы/подготовка/брони могут дополняться JSONP из таблиц; погода — отдельный hourly GitHub Action, Яндекс GraphQL, атомарная запись JSON. Новая поездка автономна: новая схема города/дня, последний проверенный прогноз, Open-Meteo вместо Яндекса по последующему указанию пользователя. Ни значения секретов, ни подключения таблиц не переносились.

В старом проекте есть Tricount-ссылка. В новом сохранён подход перехода в общий счёт, но ссылку на новую поездку пользователь задаёт сам. Суммы и старый идентификатор не перенесены.

Service worker эталона кеширует оболочку и изображения, обновляет HTML и погоду из сети. Его activate удалял все чужие кеши на origin; поскольку обе поездки на одном GitHub Pages origin, для их совместной работы очистка ограничена префиксом `nn-route-`. К новой навигации добавлены две локальные зависимости в APP_SHELL, версия повышена. Новый worker ограничен своим scope и префиксом. Это единственное сопутствующее техническое изменение старого проекта; расписание и данные не изменялись.

Общее меню — одинаковые trip-nav.js/css в обоих репозиториях. Кнопка справа сверху, native dialog с затемнением, focus containment, Escape, внешний клик, возврат фокуса. Размеры от 44 px. В старом index добавлены только подключения и небольшой резерв для кнопки в topbar.
